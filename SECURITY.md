# Security Policy

## Supported Versions

Only the latest published release is supported with security fixes.

## Reporting a Vulnerability

sru-generator has zero external runtime dependencies (Python standard library
only), which limits its attack surface, but if you find a security issue —
for example, a way crafted input could cause unexpected file writes or
resource exhaustion — please report it privately via
[GitHub Security Advisories](https://github.com/Nikolaos-Paximadakis/sru-generator/security/advisories/new)
rather than opening a public issue.

Please do not use this software to submit tax data before independently
verifying its output; see the disclaimer in [README.md](README.md) for the
project's data-accuracy scope.
